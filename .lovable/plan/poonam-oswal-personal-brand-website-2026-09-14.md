# Poonam Oswal Personal Brand Website

## Overview
Build a warm, elegant six-page personal website that presents Poonam Oswal’s public service career, literary work, poetry, social contributions, and contact information. The supplied copy will be preserved and organized into reusable content files.

## Pages and shared structure
- Add a sticky shared header with links to Home, About, Author, Poet, Social Worker, and Connect.
- Build the home page with the portrait-led opening, quote, video placeholder, concise biography, animated achievements, career highlight, services, featured books, social gallery preview, poetry feature, and contact prompt.
- Add focused `/about`, `/author`, `/poet`, `/social-worker`, and `/connect` pages with distinct page titles and metadata.
- Add a shared footer with repeated navigation, social links, and copyright.

## Visual direction
- Use soft cream, rose, burgundy, muted green, and ink tones with editorial serif headings and clean sans-serif body text.
- Use subtle paper/ink textures, restrained ornamental details, and gentle section-entry motion.
- Keep layouts mobile-first, readable, and fully responsive with accessible contrast and keyboard-friendly controls.

## Content and interactions
- Place biography, career, services, books, poetry excerpts, gallery items, navigation, and contact details in reusable data modules.
- Use polished image placeholders for the portrait, books, video, and event gallery without inventing personal imagery.
- Add animated achievement counters that respect reduced-motion preferences.
- Build the contact form with local state, validation-friendly fields, and a placeholder submit handler that logs the submitted values.

## Technical notes
- Use the project’s existing React routing system to implement the requested URLs; each page will have unique social and search metadata.
- Define all colors, typography, shadows, and decorative treatments as semantic design tokens in the global design system.
- Verify the finished site at desktop and mobile sizes, including navigation and contact form behavior.
